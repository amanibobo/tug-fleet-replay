# Demo video script (75 seconds)

Record at 1440p, dark room, cursor visible. No voiceover is fine; captions carry it.

| Time | Screen | Caption |
| --- | --- | --- |
| 0–10 s | Fleet map mid-replay at 120x, tugs moving in the main channel, battery bars under markers. | "Real Port of LA tug traffic, Dec 2–8 2024, replayed as hybrid-electric telemetry." |
| 10–35 s | Click a working tug. Detail card. Press "Open day". Hover the timeline: assist blocks in orange, SOC falling, a charging stop in green. Open the Rerun inspector and scrub. | "Each tug's day: jobs, battery curve, charging. The inspector is Rerun, loaded only when opened." |
| 35–55 s | Back to the fleet. Drag the battery slider from 6,000 kWh down to 3,000 and back up. Headline number moves. | "At 6 MWh, the published size for Arc's Curtin tugs, X% of tug-days never start the generator." |
| 55–75 s | About page: architecture diagram, assumptions table. Hold on the "estimate" labels. | "Replayed data enters through the same path a live boat's would. Every number is a labeled estimate." |

Recording tips
- Start the replay at 15:00 UTC (07:00 local), when the first ship moves of the day begin.
- Pick a tug with at least two jobs that day; the fleet list sorts active tugs first.
- Keep the slider motion slow so the number is readable in the clip.
